# Blocks Removable Print Core

A Removable print core implementation for Blocks printers by Blocks.

This extra module permits the user to call a GCODE macro that starts
a swaping routine for Blocks printcores. 
It also permits nozzle size recognition using the printcores, 
seperated by nozzle size and model.
